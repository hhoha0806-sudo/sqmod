HƯỚNG DẪN CÀI APP
  1. Tải file APK về máy.
  2. Mở file, bấm Cài đặt.
  3. Nếu báo chặn nguồn, chọn Vẫn cài đặt.
  4. Cấp quyền Hiển thị trên ứng dụng khác.
  5. Vào game bật Menu lên!
HƯỚNG DẪN CHÉP FILE
  1. Tải File trên web.
  2. Mở ZArchiver.
  3. Tìm file vừa tải (thường ở Download).
  4. Nhấn giữ file, chọn Copy.
  5. Vào Android/data/com.dts.freefireth/files/ chọn Paste.
  6. Vào Game Test!
* Dùng đúng Free Fire hoặc FF Max!
