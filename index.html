HƯỚNG DẪN CÀI APP
  1. Tải file APK về máy điện thoại.
  2. Mở file vừa tải, bấm Cài đặt (Install).
  3. Nếu điện thoại báo chặn nguồn không xác định, hãy chọn Vẫn cài đặt.
  4. Mở ứng dụng, cấp quyền Hiển thị trên ứng dụng khác (Overlay) để menu hack hoạt động.
  5. Vào game Free Fire, bật Menu lên và tận hưởng!
HƯỚNG DẪN CHÉP FILE
  1. Tải File: Bấm vào file bạn muốn tải trên web.
  2. Vào ZArchiver: Mở ứng dụng ZArchiver trên điện thoại.
  3. Vào File: Tìm đến thư mục chứa file vừa tải (thường là Download).
  4. Sao chép File: Nhấn giữ vào file, chọn Copy (Sao chép).
  5. Dán Data: Truy cập đường dẫn Android/data/com.dts.freefireth/files/ (hoặc com.dts.freefiremax) và chọn Paste (Dán).
  6. Vào Game Test: Mở game lên và trải nghiệm.
* LƯU Ý: Phải sử dụng đúng Free Fire hoặc Free Fire Max tùy theo file bạn chọn!
